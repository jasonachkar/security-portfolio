# Self-Scan Evidence

This directory stores scanner outputs generated by CI:

- `semgrep.json`
- `gitleaks.json`
- `trivy-fs.json`
- `bandit.json`
- `zap-reviewer-ui.json`
- `summary.json`
- `summary.ts`

`scripts/summarize-scans.ts` converts the raw JSON files into the TypeScript summary consumed by the reviewer UI. Missing raw files are treated as empty until the corresponding workflow has run.
